Settings, page by page

Where every setting lives.

Settings open from the notification area icon, from easyisland.exe --settings, or by asking the chat to change one. They stay above the island while you use them. Sections with the purple label are saved in the active profile; the others apply to the PC. At the bottom of the menu: Guide, Website, GitHub.

PageWhat it contains
GeneralLanguage, start with Windows, profiles and automatic switch, updates (version, Check now, daily check), pause
LookWindows 11 or Classic style, character, theme, position, screen, sizes, compact view, quick replies, resting icon, timings, sounds, search field. See Position and look
NotificationsWhat opens the island and what plays a sound, in front of a client, messages from scripts (ready command and Try). See Profiles and notifications
Chat and AI enginesDefault engine and model, keys, local servers, Instructions, Assistants, Memory (with Map), Recipes, History, Connectors, Can use the PC, Terminal mode, working folder. See The chat and AI engines
Coding agentsInstall / Uninstall for Claude Code, Codex, opencode, Antigravity, Gemini CLI, Cursor, Copilot; EasyIsland's tools in Claude Code; agents' icon; recaps. See Coding agents
Quick actionsActions, folders, suggestions for the app in use, bar of the app in use, global shortcuts. See Quick actions
TasksTasks (new, run, pause, stop, log), engines per task and helpers, limits, Heartbeat, Memory digest, Skills. See Tasks
AutomationsAutomations with When / If / Then, Try now, Log, suggestions from habits. See Automations
IntegrationsEvery integration with its fields and options, Made by you, menu order. See Integrations
WidgetsRepeatable checks. See Widgets
BackupExport and import settings (without keys)
