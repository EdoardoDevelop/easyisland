Per iniziare

Primi passi

I cinque minuti dopo l'installazione: agenti, chat, aspetto e le prime integrazioni.

#1. Apri le Impostazioni

Clic destro (o sinistro) sull'icona di EasyIsland nell'area di notifica → Impostazioni…. La finestra è divisa in pagine nel menu a sinistra e ricorda l'ultima aperta. In fondo al menu trovi i link a questa guida, al sito e a GitHub.

Suggerimento: le Impostazioni si aprono anche da riga di comando: "%LOCALAPPDATA%\EasyIsland\easyisland.exe" --settings.

#2. Collega il tuo agente di programmazione

Impostazioni → Agenti di codice → Claude Code → Installa… Vedi il diff esatto di cosa cambierà nel suo file di configurazione e il percorso del backup datato: niente viene scritto finché non confermi. Apri una nuova sessione di Claude Code e la vedrai nell'isola. Lo stesso vale per Codex, opencode, Antigravity, Gemini CLI, Cursor e Copilot: vedi Agenti di codice.

#3. Scegli il motore della chat

Impostazioni → Chat e motori AI: scegli il motore predefinito.

  • Abbonamento Claude usa il tuo piano Pro o Max tramite Claude Code installato sul PC: nessuna chiave, nessun costo in più.
  • In alternativa una chiave API (Anthropic, OpenRouter, OpenAI, Gemini), opencode, Antigravity o un modello locale (Ollama, LM Studio).

Il pallino diventa verde quando il motore è pronto. Dettagli in Motori AI.

#4. Sistema l'aspetto

Impostazioni → Aspetto: angolo dello schermo, personaggio, stile (Windows 11 o Classico), dimensioni, comportamento a isola chiusa. Oppure trascina semplicemente il personaggio dove vuoi. Vedi Posizione e aspetto.

#5. Accendi le integrazioni che usi

Impostazioni → Integrazioni: accendi quelle che ti servono (Outlook, Rete, Meteo, Appunti, 3CX, Zammad, Notion…). Compaiono nel menu dell'isola e nella Panoramica. Vedi Integrazioni.

#6. Prova

  • Passa con il mouse sul personaggio: si apre l'isola.
  • Ctrl+Space apre l'isola da qualsiasi app.
  • Copia un testo e premi Ctrl+Alt+K: la chat si apre con il testo allegato.
  • Trascina un file sull'isola: il personaggio diventa una scatola e lo inghiotte.
  • Scrivi in chat «ogni giorno alle 9 apri Outlook»: nasce un'automazione, dopo il tuo sì.
