Private on purpose.

No account, no telemetry

The network is used only for the services you configure and the update check, which you can turn off.

Secrets stay in Windows

Keys and passwords live in the Windows Credential Manager. Never on disk, never in git.

Updates after your click

Nothing installs on its own, and every update has a verified signature.

Up in two minutes.

  1. Download the installer

    Get EasyIsland-Windows-setup.exe from the releases. Current user only, no administrator.

  2. Run it

    The installer isn't signed yet: SmartScreen shows a warning, click More info → Run anyway.

  3. Connect your agents

    Notification area icon → Settings → Coding agents → Install, then pick the engine on the Chat page.
