# Settings, page by page
> section: Reference
> summary: Where every setting lives.

Settings open from the notification area icon, from `easyisland.exe --settings`, or by asking the chat to change one. They stay above the island while you use them. At the bottom of the menu: **Guide**, **Website**, **GitHub**.

**Finding a setting:** the field at the top of the menu (also **Ctrl+F**) searches every page and tab, by name, description and choices. Type a few words («in front of a client», «dark mode», «telegram token»): a click or **Enter** opens the right page and the control lights up; the arrows choose, **Esc** goes back to the page. The same from the island's field at the top: typing the name of a setting shows a **Settings** line that opens that very control.

| Page | What it contains |
|---|---|
| **General** | Language, start with Windows, updates (version, Check now, daily check), pause |
| **Look** | Windows 11 or Classic style, character, theme, position, screen, sizes, compact view, quick replies, resting icon, timings, sounds, search field. See [Position and look](05-appearance.md) |
| **Notifications** | What opens the island and what plays a sound, in front of a client, messages from scripts (ready command and **Try**). See [Notifications](06-notifications.md) |
| **Chat and AI engines** | Default engine and model, keys, local servers, Instructions, Assistants, **Memory** (with **Map**), Recipes, Direct answers and Turn log, History, Connectors, Can use the PC, Terminal mode, working folder. See [The chat](08-chat.md) and [AI engines](09-engines.md) |
| **Coding agents** | Install / Uninstall for Claude Code, Codex, opencode, Antigravity, Gemini CLI, Cursor, Copilot; EasyIsland's tools in Claude Code; agents' icon; recaps. See [Coding agents](07-agents.md) |
| **Quick actions** | Actions, folders, suggestions for the app in use, bar of the app in use, global shortcuts. See [Quick actions](15-actions.md) |
| **Tasks** | Tasks (new, run, pause, stop, log), engines per task and helpers, limits, Heartbeat, Memory digest, Skills. See [Tasks](14-tasks.md) |
| **Automations** | Automations with When / If / Then, Try now, Log, suggestions from habits. See [Automations](16-automations.md) |
| **Integrations** | Every integration with its fields and options, Made by you, menu order. See [Integrations](18-integrations.md) |
| **Widgets** | Repeatable checks. See [Widgets](25-widgets.md) |
| **Backup** | Export and import settings (without keys) |
