# First steps
> section: Getting started
> summary: The five minutes after installing: agents, chat, look and the first integrations.

## 1. Open Settings
Right-click (or left-click) the EasyIsland icon in the notification area → **Settings…**. The window is split into pages in the menu on the left and remembers the last one you opened. At the bottom of the menu you'll find links to this guide, the website and GitHub.

> **Tip:** Settings also open from the command line: `"%LOCALAPPDATA%\EasyIsland\easyisland.exe" --settings`.

## 2. Connect your coding agent
**Settings → Coding agents → Claude Code → Install…** You see the exact diff of what will change in its configuration file and the path of the dated backup: nothing is written until you confirm. Open a new Claude Code session and you'll see it in the island. The same goes for Codex, opencode, Antigravity, Gemini CLI, Cursor and Copilot: see [Coding agents](07-agents.md).

## 3. Pick the chat engine
**Settings → Chat and AI engines**: choose the default engine.
- **Claude subscription** uses your Pro or Max plan through Claude Code installed on the PC: no key, no extra cost.
- Or an **API key** (Anthropic, OpenRouter, OpenAI, Gemini), **opencode**, **Antigravity** or a local model (**Ollama**, **LM Studio**).

The dot turns green when the engine is ready. Details in [AI engines](09-engines.md).

## 4. Set up the look
**Settings → Look**: screen corner, character, style (Windows 11 or Classic), sizes, behaviour when closed. Or simply drag the character where you want it. See [Position and look](05-appearance.md).

## 5. Turn on the integrations you use
**Settings → Integrations**: turn on what you need (Outlook, Network, Weather, Clipboard, 3CX, Zammad, Notion…). They appear in the island's menu and in the Overview. See [Integrations](16-integrations.md).

## 6. Try it
- Hover over the character: the island opens.
- <kbd>Ctrl</kbd>+<kbd>Space</kbd> opens the island from any app.
- Copy some text and press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>K</kbd>: the chat opens with the text attached.
- Drag a file onto the island: the character turns into a box and swallows it.
- Write in the chat "every day at 9 open Outlook": an automation is born, after your yes.
