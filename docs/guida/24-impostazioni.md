# Impostazioni, pagina per pagina
> sezione: Riferimento
> in breve: Dove si trova ogni impostazione.

Le Impostazioni si aprono dall'icona nell'area di notifica, da `easyisland.exe --settings`, o chiedendo alla chat di cambiarne una. Restano sopra l'isola mentre le usi. Le sezioni con l'etichetta viola si salvano nel **profilo** attivo; le altre valgono per il PC. In fondo al menu: **Guida**, **Sito**, **GitHub**.

| Pagina | Cosa contiene |
|---|---|
| **Generale** | Lingua, avvio con Windows, profili e cambio automatico, aggiornamenti (versione, Controlla ora, controllo giornaliero), pausa |
| **Aspetto** | Stile Windows 11 o Classico, personaggio, tema, posizione, schermo, dimensioni, vista compatta, risposte rapide, icona a riposo, tempi, suoni, campo di ricerca. Vedi [Posizione e aspetto](05-aspetto.md) |
| **Notifiche** | Cosa apre l'isola e cosa suona, davanti al cliente, messaggi dagli script (comando pronto e **Prova**). Vedi [Profili e notifiche](06-profili.md) |
| **Chat e motori AI** | Motore e modello predefiniti, chiavi, server locali, Istruzioni, Assistenti, **Memoria** (con **Mappa**), Ricette, Cronologia, Connettori, Può usare il PC, Modalità terminale, cartella di lavoro. Vedi [La chat](08-chat.md) e [Motori AI](09-motori.md) |
| **Agenti di codice** | Installa / Disinstalla per Claude Code, Codex, opencode, Antigravity, Gemini CLI, Cursor, Copilot; Strumenti di EasyIsland in Claude Code; icona degli agenti; riepiloghi. Vedi [Agenti di codice](07-agenti.md) |
| **Azioni rapide** | Le azioni, le cartelle, i suggerimenti per l'app in uso, la barra dell'app in uso, le scorciatoie globali. Vedi [Azioni rapide](13-azioni.md) |
| **Compiti** | Compiti (nuovo, avvia, pausa, ferma, registro), motori per compito e aiutanti, limiti, Battito, Riordino della memoria, Abilità. Vedi [Compiti](12-compiti.md) |
| **Automazioni** | Le automazioni con Quando / Se / Allora, Prova ora, Registro, proposte dalle abitudini. Vedi [Automazioni](14-automazioni.md) |
| **Integrazioni** | Tutte le integrazioni con i loro campi e opzioni, Create da te, ordine del menu. Vedi [Integrazioni](16-integrazioni.md) |
| **Widget** | I controlli ripetibili. Vedi [Widget](23-widget.md) |
| **Backup** | Esporta e importa le impostazioni (senza chiavi) |
